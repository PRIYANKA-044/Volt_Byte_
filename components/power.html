Power Electronics Components

Diode

Definition

A semiconductor device that allows current flow in one direction.

Functions

  • Rectification
  • Protection
  • Signal Clipping

Applications

  • Power Supplies
  • Battery Chargers
  • Rectifiers

Zener Diode

Definition

A diode designed to operate in reverse breakdown region.

Functions

  • Voltage Regulation
  • Voltage Reference
  • Overvoltage Protection

Applications

  • Regulated Power Supplies
  • Voltage Stabilizers
  • Electronic Circuits

SCR (Silicon Controlled Rectifier)

Definition

A controlled semiconductor switching device.

Functions

  • Controlled Rectification
  • Power Control
  • Switching

Applications

  • Battery Chargers
  • Motor Control
  • Industrial Drives

TRIAC

Definition

A bidirectional thyristor used for AC switching.

Functions

  • AC Power Control
  • Switching
  • Light Dimming

Applications

  • Fan Regulators
  • Light Dimmers
  • AC Controllers

BJT

Definition

Bipolar Junction Transistor used for amplification and switching.

Functions

  • Amplification
  • Switching

Applications

  • Amplifiers
  • Electronic Switching
  • Signal Processing

MOSFET

Definition

Metal Oxide Semiconductor Field Effect Transistor.

Functions

  • High Speed Switching
  • Amplification
  • Power Control

Applications

  • SMPS
  • Inverters
  • Motor Drives

IGBT

Definition

Insulated Gate Bipolar Transistor for high power switching.

Functions

  • Power Switching
  • Motor Control
  • Voltage Regulation

Applications

  • Electric Vehicles
  • Solar Inverters
  • Industrial Drives

Rectifier

Definition

A Rectifier is a power electronic circuit that converts Alternating Current (AC) into Direct Current (DC). It is commonly built using semiconductor diodes.

Functions

  • AC to DC Conversion
  • Power Supply Generation
  • Battery Charging
  • Voltage Rectification

Applications

  • Mobile Chargers
  • Laptop Adapters
  • DC Power Supplies
  • Battery Charging Systems
  • Industrial Electronics

Inverter

Definition

An Inverter is a power electronic device that converts Direct Current (DC) into Alternating Current (AC) at the required voltage and frequency.

Functions

  • DC to AC Conversion
  • Voltage Regulation
  • Frequency Control
  • Backup Power Supply

Applications

  • UPS Systems
  • Solar Power Systems
  • Electric Vehicles
  • Home Power Backup
  • Industrial Drives
